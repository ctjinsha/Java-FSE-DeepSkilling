# Hands-on 1 - Spring Data JPA Quick Example

## Objective

Create a Spring Boot application using Spring Data JPA and MySQL to retrieve all countries from the database.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## Project Structure

- model
- repository
- service

## Database

Database Name: ormlearn

Table: country

## Sample Data

| Code | Name |
|------|------|
| IN | India |
| US | United States of America |

## Output

Displays all countries stored in the database.
